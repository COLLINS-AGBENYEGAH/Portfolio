NetGuardian, network monitoring and access control

A web platform that shows an organisation every device on its network. It discovers new devices, flags ones nobody recognises, tracks network health and can block a device at the router through the UniFi API. A cloud server cannot see inside a private network, so each organisation runs a small local agent that reports back to the shared dashboard.
